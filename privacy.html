Datenschutzerklärung

autoclip · Stand: 31. August 2026

Wer verantwortlich ist

autoclip ist ein privates, nicht-kommerzielles Programm einer Einzelperson. Es gibt keine Firma, keinen Serverbetrieb und keine Nutzer außer mir selbst. Kontakt: polesuchtkohle@gmail.com

Welche Google-Daten verwendet werden

Die Anwendung fordert genau eine Berechtigung an:

  • https://www.googleapis.com/auth/youtube.upload
    Erlaubt ausschließlich das Hochladen von Videos auf den YouTube-Kanal des angemeldeten Kontos.

Diese Berechtigung wird allein dafür genutzt, fertig bearbeitete Videos auf meinen eigenen YouTube-Kanal hochzuladen. Weitere Berechtigungen werden nicht angefordert. Die Anwendung kann mit dieser Berechtigung keine Videos lesen, ändern oder löschen, keine Kanaldaten abrufen und keine Abonnenten-, Kommentar- oder Statistikdaten einsehen.

Es werden keine Daten anderer Personen verarbeitet. Es gibt keine Anmeldung für Dritte — das Programm läuft ausschließlich mit meinem eigenen Google-Konto.

Wo die Zugangsdaten liegen

Nach der einmaligen Anmeldung speichert die Anwendung das OAuth-Token in einer Datei namens token.json im Programmverzeichnis auf meinem privaten Rechner. Diese Datei verlässt das Gerät nicht. Sie wird nicht übertragen, nicht gesichert, nicht synchronisiert und nicht in ein Code-Repository eingecheckt.

Es gibt keinen Server, keine Datenbank im Netz und keine Cloud-Speicherung von Google-Daten. Sämtliche Verarbeitung findet lokal statt. Die einzige Verbindung zu Google ist der Upload-Aufruf an die YouTube Data API.

Weitergabe an Dritte

Es findet keine Weitergabe statt. Google-Nutzerdaten werden nicht verkauft, nicht vermietet, nicht an Dritte übermittelt und nicht für Werbung, Profilbildung oder das Training von KI-Modellen verwendet.

Google API Services User Data Policy

Die Nutzung von Informationen aus Google-APIs durch autoclip erfüllt die Google API Services User Data Policy einschließlich der Limited-Use-Anforderungen.

autoclip's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Aufbewahrung und Löschung

Das Token bleibt gespeichert, bis es abläuft oder ich es lösche. Der Zugriff lässt sich jederzeit widerrufen:

  • im Google-Konto unter myaccount.google.com/permissions die Verbindung zu autoclip entfernen, oder
  • die Datei token.json lokal löschen.

Nach einem Widerruf hat die Anwendung keinerlei Zugriff mehr auf das Google-Konto.

Andere Daten

Videoclips werden über die öffentliche Twitch-API bezogen und lokal verarbeitet. Für die Erzeugung von Titel und Beschreibung wird der Transkripttext eines Clips an die Anthropic-API übermittelt. Google-Nutzerdaten sind daran zu keinem Zeitpunkt beteiligt.

Diese Website selbst setzt keine Cookies, bindet keine Skripte oder Schriftarten von Dritten ein und erhebt keine Besucherdaten. Sie wird über GitHub Pages ausgeliefert; dabei fallen bei GitHub serverseitige Zugriffsprotokolle an, auf die ich keinen Einfluss habe.
